# XREAL Air 2 Pro 原生 Android 抬頭顯示 (HUD) 導航系統

本專案使用**原生 Android (Kotlin)** 開發，專為 **XREAL Air 2 Pro** 智慧眼鏡量身打造極簡、安全、不干擾前方視野的 AR 抬頭顯示（HUD）導航指引系統。

---

## 核心設計理念：不遮蔽真實前方視線

XREAL Air 2 Pro 搭載雙眼 Micro-OLED 螢幕：
1. **OLED 物理全透光特性**：
   - 黑色像素（#000000 / RGB 0,0,0）完全關閉不發光（0 nits）。
   - 在光學稜鏡中，**純黑色 = 100% 透明**，使用者看出去就是完全不受遮擋的真實世界。
   - 本系統全屏背景強制為 #000000，徹底捨棄一般手機 App 常用的底色卡片與灰框，僅讓高對比度的指示浮現在眼前。
2. **周邊視覺邊緣佈局（Glanceable HUD）**：
   - 正前方中央約 **75% 的視野保持完全純黑**（全透光淨空），駕駛與騎士可無死角直視前方路況。
   - 轉向箭頭與道路名稱放置於視野**正上方邊緣**，符合「瞥視一眼即可理解」的人體工學原則。
3. **高辨識配色**：
   - 轉向箭頭：高亮度霓虹青綠色（#00E5FF），白天烈日下也能清晰辨別。
   - 距離提示：螢光嫩綠（#00E676）。
   - 道路名稱：冷白色（#FFFFFF）。
   - 次要指示：琥珀亮黃（#FFB300）。

## 系統核心架構

`
┌──────────────────────────────────────────────┐
│             Android 手機 (本體)               │
│                                              │
│  [Google Maps App]                           │
│        │ (發送即時導航推播)                    │
│        ▼                                     │
│  [MapsNotificationListenerService]           │
│        │ (解析轉向箭頭、道路編號、路名、剩餘距離) │
│        ▼                                     │
│  [NavStateRepository] (StateFlow 共享狀態)   │
│        ├──► [MainActivity] (鏡像預覽與控制)   │
│        └──► [XrealHudPresentation] (眼鏡投屏)│
└──────────────────────┬───────────────────────┘
                       │ Type-C DP Alt Mode
                       ▼
┌──────────────────────────────────────────────┐
│           XREAL Air 2 Pro (第二螢幕)         │
│  [1080p 極簡邊緣 HUD 浮空投射]                 │
└──────────────────────────────────────────────┘
`

1. **Google Maps 導航免付費即時連動**：
   - 透過 Android 原生 NotificationListenerService，監聽 Google Maps 即時通知。
   - **完全免申請商業付費的 Google Navigation SDK**，只要使用者在手機上啟動日常的 Google Maps 導航，眼鏡即可自動同步轉彎與道路資訊。
2. **雙螢幕 Presentation API 獨立渲染**：
   - 透過 DisplayAssistant 自動監聽 Type-C 眼鏡的插拔事件。
   - 眼鏡插入時，自動啟動 XrealHudPresentation 獨立渲染 1080p 畫面；手機螢幕仍可操作其他 App 或作為控制器。
3. **個人化視野微調**：
   - 提供水平位移（X Offset）、垂直高度（Y Offset）與縮放比例調整，適配不同使用者的臉型、鼻托高度與瞳距。
4. **離線路況情境模擬器（Demo Mode）**：
   - 內建包含「106 民族路」路口轉彎、路程推進與抵達情境的完整測試腳本，室內開發或展示時一鍵即可測試。

## 使用步驟

### 1. 於 Android Studio 開啟專案
- 支援 Android Studio Hedgehog / Iguana / Jellyfish 或更新版本。
- JDK 版本：JDK 17。
- 支援 Android 8.0 (API 26) 以上，建議搭配支援 DisplayPort Alt Mode 之手機（如 Samsung S 系列、ROG Phone 等）。

### 2. 授權與使用
1. 安裝並開啟 App。
2. 點擊「前往設定」，在系統頁面開啟本 App 的「**通知存取權限**」。
3. 使用 USB Type-C 傳輸線將 **XREAL Air 2 Pro** 連接至手機：
   - App 頂部狀態燈將變為綠色，顯示「XREAL 眼鏡已連線」。
4. 開啟手機上的 **Google Maps** 規劃路徑並開始導航：
   - 眼鏡上方將自動浮現轉向箭頭與道路名稱。
5. 若目前在室內，可直接在手機 App 點擊「**啟動模擬導航展示**」，即可在手機預覽與眼鏡端直接觀看動態示範。
