XREAL Air 2 Pro 導航 HUD - 五大核心功能升級與修復成果

🛠️ 本次重點修復與功能

  • GPS 車速 修復時速顯示 0 或未接資料問題：採用多 Provider 融合定位 (GPS + Network)，當系統 location.hasSpeed() 為 false 時，自動透過前後經緯度位移與時間差動態換算即時車速，並加入低速防漂移過濾。
  • 高德地圖 解除套件名稱限制並增加即時日誌視窗：模糊比對所有包含 autonavi、amap、map 等地圖應用；手機端主畫面新增「即時通知診斷監聽視窗」，一眼看清通知流入狀況。
  • 高德路口 路口車道線導引 (Lane Guidance)：在導航指標區動態呈現車道方塊，如 [ ↑ ] [ ↑ ] [ ↱ (高亮 Cyan) ]，清晰引導駕駛變換車道。
  • 行程進度 右側垂直路況光柱 (Traffic Bar)：畫面右側新增多色彩色垂直膠囊光柱（綠/黃/紅），自車圖標 🚗 隨行駛里程即時推進。
  • 電池圖標 放回 GPS 時速正下方並放大至 24sp：字體超清晰，支援充電 ⚡ 與低電量變色。
  • 鎖屏時鐘 消除待機大時鐘干擾：Presentation 啟用 TYPE_APPLICATION_OVERLAY 懸浮窗層級；提供一鍵 AMOLED 純黑防誤觸模式（0.01f 亮度，0 耗電，徹底避免觸發系統 AOD/鎖屏時鐘）。
