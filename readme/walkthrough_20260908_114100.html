XREAL Air 2 Pro 原生 Android 導航 HUD 成果報告

更新時間： 2026-09-08 11:41:00

一、成果亮點

  • Micro-OLED 全透光： 全黑背景 (#000000)，無任何底色容器，像素關閉物理透光，不遮蔽前方視線。
  • Google Maps 即時連動： 使用 NotificationListenerService 免費抓取道路標示與轉向箭頭。
  • 獨立雙螢幕投射： 使用 Android Presentation API 自動管理眼鏡插拔。

二、核心模組清單

模組類別 / 資源職責說明
主控制台MainActivity.kt權限引導、鏡像預覽、視野微調
眼鏡渲染XrealHudPresentation.kt獨立渲染 1080p 極簡邊緣 HUD
外接監聽DisplayAssistant.kt監聽 DisplayManager 熱插拔
通知監聽MapsNotificationListenerService.kt攔截 Google Maps 導航通知
離線模擬NavDemoSimulator.kt提供 106 民族路情境離線演示
