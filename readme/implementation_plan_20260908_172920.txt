# XREAL Air 2 Pro 導航 HUD：巨型字體、消除鎖屏時鐘與省電電池模式實作計畫
建立時間：2026-09-08 17:29:20

一、三大核心需求與解決方案：
1. 指標區放大 2 倍，GPS 速度字型放大 3 倍：
   - 轉向箭頭由 68dp 放大至 136dp
   - 轉彎距離字體由 30sp 放大至 56sp，路名放大至 50sp
   - GPS 時速由初版 32sp 放大 3 倍至 96sp（震撼大數字），單位放大至 22sp
2. 消除關閉螢幕時的鎖屏時鐘遮擋：
   - Activity 與 Presentation 啟用 setShowWhenLocked(true) 與 FLAG_SHOW_WHEN_LOCKED 穿透鎖定
   - 手機端內建「一鍵純黑省電模式」：手機螢幕全黑 0 亮度，AMOLED 不耗電防誤觸，眼鏡保持活躍，徹底不彈出系統鎖屏時鐘
3. 即時電池電量圖標與可選省電模式：
   - 眼鏡端顯示即時電池圖標與電量百分比 (🔋 85%)
   - 提供三檔省電模式：標準 (Normal) / 智慧省電 (Eco) / 極限省電 (Ultra Eco) 可自由切換
