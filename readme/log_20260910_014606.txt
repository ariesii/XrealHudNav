【第二步：核心架構修改與代碼實作】
--------------------------------------------------------------------------------
1. 模型擴充 (NavInfo.kt):
   - 在 NavInfo 資料類別中新增 `val customIconBitmap: Bitmap? = null` 屬性。
   - 作用：用以承載由 Google 地圖通知中直接截取到的原創 Bitmap 圖標，避免被粗糙的枚舉降級。

2. 關鍵字擴展 (ManeuverType.kt):
   - 擴充 `ManeuverType.fromText()`：
     - 加入「向左微轉」、「靠左」、「走左側」 -> SLIGHT_LEFT
     - 加入「向右微轉」、「靠右」、「走右側」、「下交流道」 -> SLIGHT_RIGHT
     - 加入「圓環」、「出口」、「roundabout」 -> 專屬圓環處理
     - 解決過去因文字無法命中而退回預設直行的問題。

3. 原生圖標截取引擎 (MapsNotificationListenerService.kt):
   - 實作全維度官方圖標截取函式 `extractBitmapFromNotification(notification, targetPackage)`：
     a. 優先調用 `notification.getLargeIcon()?.loadDrawable(this)` 取得原創高畫質向量轉點陣圖 (128x128)。
     b. 次選 `notification.extras.getParcelable(Notification.EXTRA_LARGE_ICON)`。
     c. 備選 `notification.getSmallIcon()?.loadDrawable(packageContext)`。
   - 將獲取的 `officialBitmap` 直接傳入 `NavInfo.customIconBitmap`。
   - 日誌記錄：`NavStateRepository.appendNotificationLog("[$source] 成功截取官方原版導航圖標 (${bmp.width}x${bmp.height})")`。

4. 畫面渲染管線 (XrealHudPresentation.kt & MainActivity.kt):
   - 眼鏡端 HUD 與手機預覽端之 `ivManeuver` 一致改為：
     ```kotlin
     if (info.customIconBitmap != null) {
         ivManeuver.setImageBitmap(info.customIconBitmap)
     } else {
         ivManeuver.setImageResource(info.maneuver.iconResId)
     }
     ```
   - 徹底實現「原汁原味 Google Maps 圖形」直接顯示。

【學習要點總結 (Takeaway)】
================================================================================
1. Android 跨 App 監聽核心技巧：
   Notification 裡往往含有官方 App 最真實的 Bitmap 資料（如 LargeIcon）。直接截取 Bitmap 比自行解析文字來猜測枚舉更穩健、更精美。
2. GitHub CLI (gh) 實用技巧：
   - `gh run list`：快速查看 Actions 執行狀態。
   - `gh run watch <RunID>`：在命令列即時盯盤編譯進度。
   - `gh run download <RunID> --dir <路徑>`：免開瀏覽器，一鍵下載 CI 產出的 APK。
