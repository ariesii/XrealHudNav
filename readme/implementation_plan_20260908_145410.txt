# XREAL Air 2 Pro 導航 HUD：轉向修正、紅綠燈倒數與時速放大計畫
建立時間：2026-09-08 14:54:10

一、核心問題剖析：
1. 高德轉向誤判修復：高德通知文字常只寫「48m 民族路」，右轉圖案在 LargeIcon 或廣播中。整合 AUTONAVI_STANDARD_BROADCAST_SEND 與 Icon 特徵解析，徹底修復右轉誤判為直走。
2. 紅綠燈秒數倒數 HUD：擷取高德即時紅綠燈資訊（紅燈 24秒 / 綠燈 15秒），以專屬 🔴 24s / 🟢 15s 高對比膠囊標籤呈現。
3. 時速表字體大幅放大：從 32sp 放大至 54sp，增強邊緣對比度與眼角餘光瞥視頻率。
