# 實作計劃記錄 (Implementation Plan)
時間戳記：20260910_020500
專案：XrealHudNav

## 任務目標
在不影響外接眼鏡畫面輸出的前提下，使手機端在不戴眼鏡時，也能完整且清晰地獲取 HUD 導航資訊，根絕文字疊加擠壓現象。

## 設計原則
1. **雙端隔離**：眼鏡端（橫向 1080p）與手機端（直向 Portrait）使用各自專屬佈局。
2. **層次流暢**：直向手機佈局採用由上而下卡片流，各資訊塊不搶佔同一水平空間。
3. **數據同步**：無論來源是高德地圖還是 Google Maps，透過 StateFlow 一併推送至眼鏡端與手機端儀表。
