高德地圖自訂通知 RemoteViews 深度解析修復報告

🔍 截圖問題剖析

實測截圖顯示高德通知僅傳入「高德地圖 | 正在導航」，原因為高德真正的路名、距離、箭頭封裝於 RemoteViews 佈局中。本次升級新增 RemoteViews 記憶體解構引擎，徹底提取出所有深層 TextView 與 ImageView 圖標。

🛠️ 核心修復技術

  • RemoteViews 解構 透過 remoteViews.apply() 遞迴提取所有 TextView 即時文字。
  • 雙重反射防禦 反射讀取 mActions，確保即便 apply 受限亦能抓到字串。
  • 圖標視覺重心 從 RemoteViews 提取箭頭 Bitmap 分析轉向。
  • 診斷強化 手機主畫面即時顯示抓取到的所有欄位細節。
