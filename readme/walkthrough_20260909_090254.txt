# XREAL Air 2 Pro 導航 HUD - 五大核心功能升級與問題修復成果

## 變更摘要
1. GPS 車速 0 / 錯誤修復：
   - 採用多 Provider 融合定位 (GPS + Network + Passive)。
   - 當系統未提供 location.speed 時，採用 Haversine 前後經緯度位移與時間差動態換算即時車速，並加入低速防抖 (<3 km/h 歸零)。
2. 高德地圖資料與通知攔截升級：
   - 放寬套件名稱比對，模糊匹配所有 autonavi/amap/map 變體與標準車載廣播。
   - 手機端主畫面新增「即時通知診斷監聽日誌視窗」，隨時查看收到的通知與廣播內容。
3. 高德車道線 (Lane Guidance) 與右側垂直路況光柱 (Traffic Bar)：
   - 新增路口車道線元件，動態顯示 [↑] [↑] [↱ (高亮 Cyan)]。
   - 新增右側垂直全程路況光柱，包含順暢綠、緩行黃、擁堵紅分段，自車小圖標隨行程推進滑動。
4. 電池電量圖標調整：
   - 移出頂部中央，放回右上角 96sp GPS 車速正下方。
   - 圖標與字型放大至 24sp/22sp，支援充電中 ⚡ 與低電量色彩警示。
5. 手機休眠待機大時鐘修復：
   - Presentation 支援 TYPE_APPLICATION_OVERLAY 懸浮窗層級（高於鎖屏 Keyguard）。
   - 手機端加入「黑屏純省電防誤觸模式」，亮度調降至 0.01f（AMOLED 0 功耗），不進入休眠因而徹底杜絕鎖屏大時鐘。

## 測試與驗證
- 本地程式碼結構審查通過，所有備份檔案均集中管理於 backup/ 目錄，res/ 無污染。
- NavDemoSimulator 支援完整 5 個情境動態驗證（包含車道右轉高亮、垂直路況光柱、紅綠燈倒數 24s/5s/18s、超速 56km/h 警示等）。
