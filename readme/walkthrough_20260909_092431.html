XREAL Air 2 Pro 插入 USB 閃退問題修復報告

🔍 閃退原因剖析

在 Presentation 內部呼叫了 setType(TYPE_APPLICATION_OVERLAY)。由於 Presentation 的 Context 為 Activity 且綁定在外接 Display 上，變更為全域懸浮窗 Type 會破壞系統 Display Token，導致 Android 在 show() 時拋出 BadTokenException 閃退。

🛠️ 修復措施

  • 修復 移除 Presentation 內部 setType：恢復乾淨的外接螢幕 Window 屬性。
  • 防護 DisplayAssistant 增加全面 try-catch：防止外接設備插拔時主程式崩潰。
  • 時鐘解決方案 AMOLED 黑屏純省電防誤觸模式：手機螢幕 0 亮度運作，徹底杜絕鎖屏大時鐘，安全穩定。
