📖 Antigravity 專案操作與 GitHub 指令學習日誌

記錄時間：2026-09-10 01:46:06 | 專案：XrealHudNav (XREAL Air 2 Pro 導航 HUD)

🎯 本階段任務目標

解決 Google Maps 轉向箭頭除向右轉外其餘無法顯示之問題，實現 Google Maps 原版官方導航圖標直通截取，並將完整終端機與 GitHub Actions 操作命令建檔以利學習。

步驟一：修改前檔案防護與時間戳備份

PowerShell 
Copy-Item 'app/src/main/java/com/xreal/hudnav/model/NavInfo.kt' 'backup/NavInfo_20260910_014500.kt.bak'
Copy-Item 'app/src/main/java/com/xreal/hudnav/model/ManeuverType.kt' 'backup/ManeuverType_20260910_014500.kt.bak'
Copy-Item 'app/src/main/java/com/xreal/hudnav/presentation/XrealHudPresentation.kt' 'backup/XrealHudPresentation_20260910_014500.kt.bak'
Copy-Item 'app/src/main/java/com/xreal/hudnav/service/MapsNotificationListenerService.kt' 'backup/MapsNotificationListenerService_20260910_014500.kt.bak'
Copy-Item 'app/src/main/java/com/xreal/hudnav/MainActivity.kt' 'backup/MainActivity_20260910_014500.kt.bak'

學習重點：修改程式碼前必先備份至獨立的 backup/ 目錄，絕不可放在 res/ 內，避免 Android AAPT 編譯器因未知副檔名產生報錯。

步驟二：核心程式碼重構要點

  • NavInfo.kt：新增 customIconBitmap: Bitmap? 屬性，突破固定 enum 限制。
  • MapsNotificationListenerService.kt：實作 extractBitmapFromNotification，優先調用 Notification.getLargeIcon() 提取 Google Maps 原版 128x128 向量轉點陣圖。
  • XrealHudPresentation.kt & MainActivity.kt：改為優先繪製 customIconBitmap，實現圓環、微偏、岔路等原汁原味呈現。
  • ManeuverType.kt：擴展「向左微轉」、「走左側」、「下交流道」等關鍵詞對應。

步驟三：Git 版本控制與遠端推送

Git 
# 1. 查看修改差異
git diff app/

# 2. 暫存變更
git add app/ backup/ readme/

# 3. 提交本地 Commit
git commit -m "feat: 深度截取 Google Maps 官方原版導航圖標訊號，直接於 HUD 呈現原生向量轉向圖"

# 4. 推送至遠端儲存庫觸發 CI/CD
git push origin main

學習重點：Commit Message 使用台灣用語與明確的 feat/fix/chore 前綴，有助於追蹤變更紀錄。

步驟四：GitHub Actions (CI/CD) 監控與成品下載

GitHub CLI 
# 1. 查詢最新自動編譯任務 Run ID
gh run list --limit 2

# 2. 終端機即時監看編譯進度
gh run watch 34384509162

# 3. 編譯成功後，下載雲端產出的 APK
Remove-Item 'release-apk/XrealHudNav-debug-apk/app-debug.apk' -Force -ErrorAction SilentlyContinue
gh run download 34384509162 --dir release-apk

# 4. 將編譯好的 APK 提交並推送到 GitHub
git add release-apk/XrealHudNav-debug-apk/app-debug.apk
git commit -m "chore: 更新支援 Google Maps 原版導航圖標訊號直通之最新 debug APK"
git push origin main

學習重點：善用 gh 命令列工具，無需開啟瀏覽器即可完全掌控 GitHub Actions 流程並自動化下載最新安裝檔。
