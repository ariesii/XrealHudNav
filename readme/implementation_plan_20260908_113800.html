XREAL Air 2 Pro 原生 Android 導航 HUD 實作計畫

建立時間： 2026-09-08 11:38:00

一、核心需求分析

  • 裝置： XREAL Air 2 Pro（Type-C DP Alt Mode 第二螢幕輸出，雙眼 Micro-OLED）
  • 功能： 轉向標示（Turn-by-turn Arrow）與道路標示（Road Name / Distance）
  • 關鍵限制： 在不影響畫面的情況下顯示（極簡邊緣配置，視野正前方完全無遮蔽）

二、關鍵技術原理

  1. Micro-OLED 物理全透光： 背景強制為 #000000，黑色像素關閉不發光即為完全透明。
  2. 非侵入式邊緣配置： 視野中央 75% 純黑透明，資訊固定於視野上方邊緣偏右。
  3. Google Maps 即時通知監聽： 利用 NotificationListenerService 免費無痛解析轉彎標示。
  4. 雙螢幕渲染： Android Presentation API 自動監聽眼鏡插拔。
