高德地圖 16 導航路口、轉向資訊與車載廣播雙通道整合

核心問題與技術突破

  • 高德 SDK vs 手機高德地圖 App：使用者引用之 AMapNavi 需高德 Key 且屬於自行開發地圖，HUD 外接眼鏡則需對接使用者手機上安裝之官方高德地圖 App。
  • Android 11+ 套件可見性：加入 <queries> 標籤以解除 Android 系統對高德地圖的讀取限制。
  • 高德車載標準廣播：支援 AUTONAVI_STANDARD_BROADCAST_SEND，直接獲取精確距離、路名、轉向、車道線與紅綠燈狀態。
  • RemoteViews 資源載入修復：改用 createPackageContext 載入高德地圖 XML 資源，杜絕崩潰問題。
