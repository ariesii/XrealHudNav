任務說明 (Task): 手機端 HUD 即時預覽置頂、數據看板 (Inspector) 與免插眼鏡模擬測試
時間: 2026-09-09 18:32:00

【核心訴求與痛點】
1. 使用者反映「還是沒看到」，每次測試都必須反覆插拔 XREAL Air 2 Pro 眼鏡，極為不便。
2. 原先手機端的 HUD 預覽在「未開始導航 (isNavigating == false)」時會將所有畫面元件強制全黑隱藏 (View.GONE)，導致使用者在手機上只看到黑屏，誤以為完全沒有接收到任何資料。
3. 手機端缺少即時變數檢視看板 (Inspector)，使用者無法直觀確認地圖來源、下一路名、轉向動作、路口距離、車道線與紅綠燈數據是否有流入。

【執行工作清單】
- [x] 更新 activity_main.xml，將 HUD 鏡像預覽卡片「置頂」呈現，打開 App 第一眼即可看到。
- [x] 移除預覽時「未導航即全黑隱藏」的限制，改為「待機儀表盤常態呈現」，即時顯示 GPS 車速與電量。
- [x] 新增「📊 HUD 即時接收數據看板 (Inspector)」，以獨立網格清楚列出地圖來源、轉向動作、路口距離、目標路名、紅綠燈與車道線。
- [x] 新增「⛶ 全螢幕 HUD 模擬模式」，支援手機橫屏 1:1 滿版模擬外接眼鏡顯示，按返回鍵即可退出。
- [x] 新增「🧪 一鍵快速測試注入工具組」，提供【高德右轉 48m】、【Google 左轉 150m】與【紅綠燈倒數 28s】三個按鈕，免出門即可手動驗證眼鏡與預覽畫面。
- [x] 增強 MapsNotificationListenerService 的生命週期日誌追蹤 (連線狀態、通知進入捕捉)。
